# Repository contributor guidance

Follow [CONTRIBUTING.md](CONTRIBUTING.md) and its shared project policies.
For workspace or CI changes, use
[the privacy and trust policy](docs/contributing/workspace-and-ci.md).
Use one grouped PR per coherent feature; implementation steps belong as commits.
Keep unfinished work and requested revisions draft. Do not merge main without
Jack's approval, and respect an explicit instruction not to merge.

Before UI/MCP qualification, read
[the surface policy](docs/contributing/surface-qualification.md) and
[the coverage ledger](docs/qualification/surface-coverage.json). The broad run
remains paused until the user resumes it. Preserve incoming work and recovery data.
