noBS CAD **0.2.1** is a follow-up to
[0.2.0](https://github.com/jackControls/noBS-CAD/releases/tag/v0.2.0): fixes and
capability across sketching, the native viewport, the kernel boundary, MCP and the
offline knowledge base.

## What changed since 0.2.0

**Sketching** — face boundaries can be projected into a sketch, with a hardened
projection and tool lifecycle (#147); concentric between a point and a circle or arc
(#144); circle and center-rectangle centers are selectable again (#154); the inline
dimension editor selects its value when it opens (#148).

**Native viewport** — the ground and sketch grid scale with the view and stay
continuous while zooming and panning (#158); inside-corner edge strokes are lifted
clear of their faces (#161); each document tab keeps its own camera (#159).

**Kernel** — a fillet or chamfer that would otherwise consume a wall now blends the
edge instead of failing (#160).

**Desktop shell** — further progress on the interface replacement (#153); native
navigation stays responsive through the modeling lifecycle (#150); an opened project
adopts its file name while the design is untitled (#157).

**MCP and agents** — feature summary, warnings, `check`, `solid_box` and print tools
return useful feedback to an agent (#162); JSONC script includes plus `export_script`,
distinct from `cad_script` (#163); grouped help without a desktop document; `cam` in
the `cad_set_focus` schema; `export_script` staleness judged by mutations rather than
by time.

**Help and knowledge** — one help surface (`limo-cad-help` crate, `cad_help` tool) over the
machine-design knowledge base, with search, generated inventory and attribution
checks (#145).

**Packaging and CI** — a shared Windows OpenCASCADE setup action, enforced fast gates,
sharded native tests, and a scheduled workflow that keeps the default-branch ARM SDK
cache warm, so a release tag no longer recompiles OpenCASCADE for Windows ARM64 from
scratch (#146). The release page was also split so installers stay here and media lives
in the companion release.

## Project compatibility

The `.nbcad` container version is still 1. The model schema advanced from 7 to 9:

- 0.2.1 opens projects written by 0.2.0 and earlier; older schemas migrate forward when
  the project is loaded.
- A build older than 0.2.1 refuses a project saved by 0.2.1 ("not supported") instead of
  opening it partially. While the format is pre-1.0, keep the matching build with a
  project you care about.
