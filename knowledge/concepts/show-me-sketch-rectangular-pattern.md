1. Choose Rectangular Pattern and select the Ø3 circle centered at (14,14).

2. Use angle 0°, spacing 6 mm and count 3. With second count 1, apply to create one row.

3. Undo the row, select the original again, and keep count 3. Set second angle 90°, spacing 10 mm and count 2.

4. Apply the two-direction pattern. Six circles occupy x=14,20,26 and y=14,24; no extra original is added.
