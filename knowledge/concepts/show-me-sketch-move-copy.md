1. Open Move/Copy and select the circle centered at (16,16).

2. Leave Copy off; set X distance 8 and Y distance 0, then apply.

3. The center is now (24,16). Select it, enable Copy, and set X 0 and Y 12.

4. Apply the copy. Two equal circles remain at (24,16) and (24,28); moving had kept only one.
