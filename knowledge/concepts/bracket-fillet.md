1. Start with the extruded bracket. The inner bend is already rounded; this example focuses on the four outer corners.

2. Choose Fillet and select the four outer corner edges shown in the example. Set Radius to 3 mm and check the preview.

3. Apply. Edit the fillet to change its radius or selected edges. Cut uses this same bracket after the remaining edge breaks and base holes are prepared.
